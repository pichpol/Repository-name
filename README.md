# Крутой_прокат228 - прокат фототехники и настольных игр

Приложение для учета клиентов, техники и настольных игр, выдаваемых в прокат.

## Автор
Мельникова Варвара, РПО 24/2

## О проекте
Тема: Прокат. 
Наше заведение - это городской пункт проката "Крутой_прокат228", где можно взять на время профессиональную фототехнику или редкие настольные игры. Приложение поможет сотрудникам пункта быстро оформлять выдачу, следить за тем, кто и что взял, и не забывать о сроках возврата. В отличие от обычных прокатов, у нас уникальный ассортимент: от объективов до настольных стратегий. Пользоваться приложением будут администраторы за стойки выдачи и менеджеры, ведущие базу.

## Схема базы
```mermaid
erDiagram
    Clients ||--o{ Rentals : "берет в аренду"
    Items ||--o{ Rentals : "выдается в аренду"

    Clients {
        int Id PK
        string FullName "ФИО клиента"
        string PhoneNumber "Номер телефона"
        int LoyaltyPoints "Бонусные баллы"
    }

    Items {
        int Id PK
        string Title "Название предмета"
        string Category "Категория (Фото/Игра)"
        int PricePerDay "Цена за сутки (руб.)"
    }

    Rentals {
        int Id PK
        int ClientId FK "Кто взял"
        int ItemId FK "Что взял"
        DateTime StartDate "Дата выдачи"
        DateTime EndDate "Дата возврата"
        int TotalCost "Итоговая стоимость (руб.)"
        bool IsReturned "Возвращено ли"
    }
